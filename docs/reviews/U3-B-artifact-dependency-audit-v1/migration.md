## Old/new interpretation and rollback

Old reports stay at their exact engine/suite/implementation and input/result bindings.
Old artifacts keep unversioned full support rules; historical replay uses a compatible
historical implementation or explicit integrity-only inspection with no currentness claim.
New-policy artifacts require their recognized policy and their exact reviewed generation
closure. Do not drop the old enforcement branch to make migration convenient.

Rollback is a new normal commit plus Javid's explicit selection/adoption of a complete
compatible artifact/source pair. Merely reverting scripts while keeping a new-policy
artifact, or replacing only its support JSON with the old one, is not a valid rollback.
Git retains old source and complete artifact history; no force push or hand-edited hashes.
