Implement admission independently in Rust; do not call Python validators or trust a
prevalidated flag. Order refusals as follows, matching public component boundary behavior:

1. Strict JSON/model shape and canonical hash/closure joins, then required component
   operand_access exactly X/W/Y before helpers can index it. A full-job precondition parses
   its closure and checks access before installed validate_job. No KeyError/panic acceptance.
2. External invocation/checkpoint/registry/profile/engine joins. Expected-negative profile
   entries deliberately stop at TestVariantNotAdmitted. A self-rehashed profile is not a
   new trusted anchor. Validate all closure points, not just the selected point.
3. DAG/resource bounds, alignment/banks, producer and final-consumer sets, live alias,
   routes, rank/policy/scope/shape, coverage/dependencies, exact accumulator/operand capacity,
   second slot, transfer ranges/channel/stripe/engine/route checks. @1 metadata retains
   historical meaning. Only @2 enables explicit transient accumulator use/lifetime readers.
   False producer -> InvalidDependency; wrong transient producer core -> InvalidResource;
   nonterminal/missing consumers -> InvalidDependency; unordered overlap -> LiveBufferAlias;
   exact size or capacity mismatch -> CapacityExceeded. SRAM uses SramCapacityExceeded.
4. Three completeness guards after resource admission: canonical barrier owner;
   uninitialized compute X/W each populated by its exact entire destination buffer range;
   cold Y source writes partition the complete output once, no gaps/overlap. Refuse
   InvalidResource or InvalidTransfer respectively. These already run in A's assembly,
   component bundle load/export, full-job load/export and prepare_component_job. They are
   consumer guards, not claims that the lower-level resource primitive already implements
   them. Preserve them in every future native/public component path. K2 remains unchanged.
5. Only then allocate native state and dispatch. Revalidate exact result joins and /2
   observations at output; never replace missing observations with expected declarations.

For each fragment retain actual credit acquisition, request/port/NoC/memory transitions,
response commit/ack and credit release. Activity references join exact dispatch ordinals;
clock calls identify their activity, request and receiving mechanism. Resource intervals
cover occupied subphases, not elapsed wait/alignment. Channel service retains rational
state; queue reporting uses integer finite windows. Zero-hop and zero-duration activities
remain linked even when no positive-duration critical interval exists. Follow actual tight
resource/credit/dependency/sequence causes with the candidate's stable tie tuple. Full
phase inventories, mechanism cycle/rational laws, credit maxima, counts from completions,
transfer boundaries and allocation actual-use coverage require B's independent checker.
A schema-valid synthetic carrier is never sufficient for native acceptance.

barrier owner, stale and fully rehashed closure attacks; @1 persistent equal footprints;
@2 C04 and256x255→256x256; multiple terminal consumers; independent cores/overlap; false
DMA/barrier/other-buffer producers; exact-end/beyond capacity; queue owner/channel/engine/
request/population and nonnull-domain bypass; missing/relabelled/untight causal activities;
zero-hop61000 versus incorrect61667. Remove each essential guard in a private mutant,
show its discriminating test fails, restore exact bytes and rerun affected controls.
