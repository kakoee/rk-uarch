# Artifact dependency audit — milestone supplement

This supplements, and does not replace or implement, the
[v1 dependency-audit proposal](../U3-artifact-dependency-repair-proposal-v1/README.md).
The audit scope, exclusions, evidence requirements and separate human policy/migration
decision remain unchanged.

**Milestone:** before M's protected mapped-carrier installation under `contract/`, complete
the dependency audit and present its proposed policy/migration decision. If a safe repair
is not ready, return an explicit decision to Javid to retain current enforcement and budget
the required M/K2/B human adoption cycles. Record that decision before installation; do not
silently waive currentness or block indefinitely on an unspecified “later” repair.

B owns the audit with A consultation. This is a deadline for an informed decision, not
automatic acceptance of a narrower inventory, permission for CI generation, or a shortcut
around U0002. No enforcement or artifact bytes changed in this supplement.
