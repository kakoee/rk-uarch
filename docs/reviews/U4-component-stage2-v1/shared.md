## Test quality and scope

Reproduce consistent resealed forgeries, not only single-field edits that another join
rejects. A baseline failure must be a behavioral assertion, not collection/import/setup,
source-fingerprint, selection-hash or message-only collateral failure. For the unsafe
admissions and timing/cause defects, show the forged value actually gets through when the
essential defense is disabled, then refuses with it restored. Include valid controls.
Pin appropriate public error code and diagnostic detail; distinguish expected refusal
ordering checks from evidence that a particular semantic guard is necessary.

Build a guard-to-invariant/test matrix covering the reviewed sweeps (46 contract guards,
55 checker guards, adjusted explicitly for changed code). Each essential invariant needs a
consistent witness and discriminating test. A guard may be intentionally redundant or
unreachable under admitted structure: demonstrate and document that instead of inventing
one mirror test per line. Source-digest failures do not count as behavioral mutation kills.
Exclude identity-only tests from mutation scoring, while retaining them in ordinary package
integrity checks. Record surviving mutations honestly; resolve semantic gaps or disposition
them, never relabel masked tests as coverage.

Use durable tests in existing ordinary discovery roots. A proposes exact protected contract
test postimages; B provides checker tests/helpers with stable import paths. Proposed examples
are not native results. Include final installed-path collection IDs and an invocation matching
normal pytest/CI filters; no copying .py.txt at test time, untracked sibling helper dependency,
new silent skip or conditional waiver to hide absent implementation. The two named human L1
skips remain explicit and separate. Installation must activate the reviewed tests alongside
the semantics; five implementation files alone are insufficient.
